# 📊 AI Sales Analytics Dashboard

An interactive **AI-powered Sales Analytics Dashboard** built with **Python, Streamlit, Pandas, and Plotly**.

The application helps users explore sales data using filters, KPIs, interactive charts, and a natural-language question/search interface.

## 🚀 Live Demo

**Streamlit App:**

https://ai-sales-analytics-yeswanth.streamlit.app/

## ✨ Features

- 📊 Interactive sales dashboard
- 🔎 Search / ask questions about sales data
- 🌍 Filter sales by region
- 📦 Filter sales by category
- 💰 Total sales KPI
- 🧾 Total records KPI
- 📈 Average sale KPI
- 🛒 Units sold KPI
- 🌎 Regional sales visualization
- 📦 Category-wise sales analysis
- 💡 Quick sales questions
- 📱 Interactive Streamlit interface
- ☁️ Online deployment with Streamlit Community Cloud

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/yeswanthdiv24/AI-Sales-Analytics.git
cd AI-Sales-Analytics
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run dashboard/app.py
```

The dashboard will open at:

```text
http://localhost:8501
```
