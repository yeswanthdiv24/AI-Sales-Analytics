# 📊 AI Sales Analytics Dashboard

An interactive **AI-powered Sales Analytics Dashboard** built using Python, Streamlit, Pandas, and Plotly.

The dashboard helps users explore sales performance through interactive filters, KPIs, visualizations, and natural-language questions.

## 🚀 Live Demo

👉 **[Open AI Sales Analytics Dashboard](https://ai-sales-analytics-yeswanth.streamlit.app/)**

## ✨ Features

- 🔎 Search and ask questions about sales data
- 🌍 Filter sales by region
- 📦 Filter sales by category
- 💰 Total Sales KPI
- 🧾 Total Records KPI
- 📈 Average Sale KPI
- 🛒 Units Sold KPI
- 🌎 Regional sales analysis
- 📦 Category-wise sales analysis
- 📊 Interactive Plotly charts
- 💡 Quick sales questions
- 🌐 Online deployment with Streamlit Community Cloud

🎯 Project Objective

The objective of this project is to create an interactive sales analytics platform that allows users to quickly understand sales performance, identify regional and category trends, and ask questions about their sales data.

📊 Dashboard Capabilities

Sales KPIs

The dashboard provides:

* Total Sales
* Number of Records
* Average Sale
* Units Sold

Interactive Filters

Users can filter the dashboard using:

* Region
* Category

AI / Search Analysis

Users can enter questions such as:
What is the total sales?
Which region has the highest sales?
Which category performs best?
How many units were sold?
